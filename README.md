# NovaCart

## Краткое описание

NovaCart — это форк OpenCart и ocStore с открытым исходным кодом, предоставляющий готовую платформу для создания интернет-магазина. Важно отметить, что этот репозиторий является форком оригинального проекта; изменения и поддержка могут отличаться от upstream (opencart ocstore).

## Поддержка и баг-трекер

Это форк — по всем вопросам, связанным с установкой, поддержкой, модулями или функциональностью, пожалуйста, обращайтесь на сайт разработчика: https://gbit-studio.com

Если проблема явно связана с ядром OpenCart, имеет смысл сначала проверить официальные ресурсы и форумы OpenCart:

1. Официальный репозиторий OpenCart/ocStore для истории изменений и upstream-исходников.

Пожалуйста, перед созданием отчёта проверьте:

- Документы `install.txt` и `upgrade.txt` в архиве.
- Список изменений upstream (changelog) и существующие issues.

## Установка и обновление

Прочитайте файлы `install.txt` и `upgrade.txt` в корне репозитория. Для вопросов по установке и обновлению используйте https://gbit-studio.com
